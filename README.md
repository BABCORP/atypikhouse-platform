# AtypikHouse Platform

Scalable full-stack marketplace for booking unique accommodations, featuring secure multi-role dashboards and a seamless user experience.

## 🚀 Overview

AtypikHouse is a web platform designed to connect travelers with unique stays such as cabins, yurts, and tiny houses.

The platform includes:
- User booking experience
- Host property management
- Admin dashboard

## ⚙️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
